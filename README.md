# AI IT Helpdesk Agent

A portfolio-grade AI helpdesk application built progressively with Python, AWS, Amazon Bedrock, RAG, APIs, and agentic automation.

## Goal

Build an AI IT Service Desk Agent that can:

1. Understand an employee's IT problem.
2. Search an approved IT knowledge base.
3. Provide grounded troubleshooting guidance.
4. Create and retrieve support tickets through tools.
5. Escalate appropriately to a human.
6. Run on AWS.
7. Demonstrate responsible AI, security, testing, logging, and cost awareness.
